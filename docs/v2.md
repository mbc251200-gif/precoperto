
# PreçoPerto V2

## Implementado no scaffold
- Geolocalização via Geolocator
- Serviço de upload de imagens para Supabase Storage
- Notificações locais
- AdMob com ID de teste
- Analytics de eventos publicitários
- Regra inicial antifraude
- Chat Realtime via Supabase Stream
- Página de planos
- Painel administrativo básico
- Tabelas de tokens e planos
- Storage bucket e RLS

## Configuração
Adicione ao `pubspec.yaml`:
- geolocator
- image_picker
- google_mobile_ads
- flutter_local_notifications

Depois execute `flutter pub get`.

Para Android, configure permissões de localização no AndroidManifest.
Para iOS, configure NSLocationWhenInUseUsageDescription.
Para AdMob, substitua os IDs de teste pelos IDs reais somente após configurar sua conta.

## Importante
O preço de anúncios por visualização não é garantido. O AdMob/rede define impressões válidas, e receita varia por país, inventário, demanda e formato.

- autenticação robusta e recuperação de conta
