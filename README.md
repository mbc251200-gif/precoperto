# PreçoPerto — MVP funcional

Esta versão evolui o scaffold para um MVP conectado ao Supabase quando as variáveis `SUPABASE_URL` e `SUPABASE_ANON_KEY` são fornecidas.

## Funcionalidades
- Home
- Busca
- Resultados
- Detalhes da oferta
- Cadastro/login
- Cadastro de vendedor/serviço
- Criação de oferta
- PostgreSQL/Supabase
- RLS inicial
- Modelo de monetização por publicidade e patrocinados

## Executar
Veja `docs/setup.md`.

Sem Supabase configurado, o app continua abrindo em modo demonstração com ofertas locais.
